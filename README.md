# Darkgrid

A native iOS/iPadOS Safari Web Extension that applies a true-black OLED theme with configurable neon accents across Safari websites.

## Core features

- True-black webpage theming
- Cyan, red, green, and purple neon presets
- Custom accent color and hex input
- Edge-glow mode
- Master enable/disable toggle
- Per-site exclusions
- Local-only settings and no backend
- Safari Web Extension architecture

The project is built as an iOS host app plus a Safari Web Extension. Website access is granted through Safari once; Darkgrid does not present per-site permission prompts of its own.
